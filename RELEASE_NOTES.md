## Clawd for Android — v1.0

Пиксельный питомец поверх экрана Android. **Без ИИ, без сети, без телеметрии** — манифест даже не запрашивает `INTERNET`, приложение физически не может ничего отправить.

### What you get

- Живёт поверх всех окон (foreground-сервис + `TYPE_APPLICATION_OVERLAY`).
- Тапается только сам спрайт: интерактивное окно пересчитывается каждый кадр под фактическую геометрию, поэтому тапы по YouTube и иконкам уходят приложению под питомцем, а не ему.
- Тап, двойной прыжок, долгий тап (гладим — сердечки), 8 тапов подряд (распыляется на пиксели).
- Перетаскивание пальцем и швыряние через весь экран с отскоками.
- Сон через N минут без внимания: тело **испаряется на пиксели**, во сне летит «Z» и видятся сны.
- **Танцует под музыку** — определяет трек через `AudioManager.isMusicActive`, прыгает в такт, машет руками, краснеет.
- **Режим тамагочи** — настроение, сытость, бодрость, кормление, игры, сон, смерть от голода и воскрешение по секретному коду.
- 3 размера, 6 окрасов, живые превью, RU/EN.

### Requirements

- Android 8.0 (API 26) или новее.
- Разрешение «отображать поверх других приложений».
- Для OEM (Xiaomi, Huawei) включите «Отключить оптимизацию батареи», иначе сервис убивают.

### Install

Скачайте `app-debug.apk` из этого релиза, разрешите установку из неизвестных источников и откройте файл. В приложении: выдайте разрешение на оверлей → выберите параметры → **«Запустить питомца»**.

> Это debug-сборка — подписана отладочным ключом, для установки может потребоваться разрешить «неизвестные источники». Для продакшена соберите release через `gradle :app:assembleRelease`.

### Build from source

```bash
# JDK 17, Android SDK 35
gradle :app:assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

Открывается и в Android Studio (Ladybug или новее), Gradle 8.9 подтягивается сам.
